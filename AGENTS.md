# Product updates and release notes

Read `.gemini/styleguide.md` completely before writing or editing product updates, release notes, or their visuals. The guide is the canonical editorial standard and is also loaded by the monthly content synthesizer.

For application screenshots, follow its **Product screenshot standard**. Choose the operator's device and view, use meaningful real demo data, and verify the final pixels and published image. A square crop or an empty setup screen is not an acceptable substitute for a device-framed product screenshot.

If a browser connector reports a UI blocker, inspect the actual browser window through native computer use before attributing the failure to a panel or asking the user to intervene. Use the native computer-use fallback when available; do not bypass real security or permission warnings.
